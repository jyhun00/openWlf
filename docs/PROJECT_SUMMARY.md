# OpenWLF 프로젝트 요약 보고서

## 프로젝트 개요

**OpenWLF (Open Watchlist Filtering System)**는 금융기관의 **AML(Anti-Money Laundering)** 컴플라이언스를 위한 감시목록 필터링 시스템입니다. 고객 정보를 OFAC, UN, EU 제재 리스트와 실시간 대조하여 자금세탁 위험을 식별합니다.

| 항목 | 내용 |
|------|------|
| **기술 스택** | Java 17, Spring Boot 4.0.1, Gradle 9.2+, JPA/Hibernate |
| **데이터베이스** | H2 (개발), PostgreSQL/MySQL (운영) |
| **API 문서** | SpringDoc OpenAPI 3.0 (Swagger UI) |

## 주요 기능

| 기능 | 설명 |
|------|------|
| **고객 필터링** | 9가지 매칭 알고리즘으로 고객-감시목록 대조 (EXACT, FUZZY, PHONETIC, JARO_WINKLER, NGRAM, KOREAN 등) |
| **Alert 관리** | 6단계 상태 관리 (NEW → IN_REVIEW → ESCALATED → CONFIRMED/FALSE_POSITIVE/CLOSED) |
| **Case 관리** | Alert를 Case로 전환, 담당자 배정, 우선순위 관리, SAR 보고 추적 |
| **제재 리스트 동기화** | OFAC/UN/EU 리스트 자동 다운로드 및 파싱 (Cron 스케줄링) |
| **감사 추적** | 모든 변경사항 기록, 컴플라이언스 요구사항 충족 |

## 점수 체계

```
┌─────────────────────────────────────────────────────────┐
│   0-49점: 정상 통과    │   50-69점: 검토 필요           │
│   70-100점: 경보 발동 (Alert 생성, 거래 차단)           │
└─────────────────────────────────────────────────────────┘
```

## 모듈 구조

```
openWLF/
├── api-module/       → REST API 진입점 (Controller, DTO)
├── core-module/      → 핵심 비즈니스 로직 (필터링, 규칙 엔진, 스코어링)
├── data-module/      → 데이터 접근 계층 (Entity, Repository, Service)
├── config-module/    → YAML 기반 규칙 설정 로더
└── batch-module/     → 배치 처리 (제재 리스트 동기화)
```

---

## 설계 특징

- **SOLID 원칙 준수**: Strategy, Registry, Facade 패턴 적용
- **동적 규칙 엔진**: YAML 설정으로 규칙 추가/수정 가능
- **확장 가능한 매칭**: 새로운 알고리즘 쉽게 추가 가능
- **완전한 감사 추적**: AML 컴플라이언스 요구사항 충족
